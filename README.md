# 문장학교 예약 앱 - 30분 단위 스마트 슬롯 버전

수정 내용

- 정규수업 예약 슬롯은 30분 단위로 유지합니다.
- 90분 수강권은 90분 수업 기준으로 예약 가능 여부를 계산합니다.
- 120분 수강권은 120분 수업 기준으로 예약 가능 여부를 계산합니다.
- 정규수업 사이에는 30분 휴식이 필요합니다.
- 하루 마지막 수업은 수업 종료 후 휴식 시간을 강제로 요구하지 않습니다.
- 20:00-22:00 120분 수업이 가능하도록 유지합니다.
- 20:30-22:00 90분 수업이 가능하도록 유지합니다.
- 원데이 클래스가 있는 경우, 정규수업은 원데이 시작 최소 10분 전에는 끝나야 합니다.
- 수강생 화면에는 복잡한 내부 규칙을 보여주지 않고 가능한 시간만 표시합니다.

Supabase SQL 추가 실행은 필요 없습니다.
