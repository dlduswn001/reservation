# 문장학교 예약 사이트

이번 버전에는 다음 기능이 포함되어 있습니다.

- 일러스트 배경
- 관리자 메뉴 탭
- 수강생 등록·수정·삭제
- 이름, 전화번호 뒷자리, 수강권, 메모, 이용 상태 수정
- 수강생별 과거 수강 기록 추가·수정·삭제
- 예약으로 생성된 지난 수업 기록 확인
- 수강생의 내 수강 기록 화면에 관리자가 입력한 기록 표시
- 예약 가능 시간 삭제
- 원데이 클래스 등록·삭제 및 정원 5명
- 80분 수업과 10분 정리 시간
- 수업 6시간 전 예약·취소 규칙

## Supabase

`SUPABASE_MIGRATION.sql` 전체를 Supabase의 SQL Editor에서 한 번 실행해 주세요.
기존에 실행한 내용이 있어도 다시 실행할 수 있도록 작성되어 있습니다.

## GitHub 업로드

압축을 푼 뒤 이 폴더 자체가 아니라 `app`, `lib`, `public`, `package.json` 등 폴더 안의 내용물 전체를 저장소 첫 화면에 업로드합니다.
