# 문장학교 예약 앱 - 정규수업 예약 속도 개선 최종 버전

이번 버전은 정규수업 예약하기 화면이 느려지는 문제를 줄이기 위해 예약 가능 시간 계산 방식을 바꾼 버전입니다.

## 핵심 수정

- 정규수업 예약 화면 진입 시 전체 날짜를 한 번에 계산하지 않습니다.
- 수강생이 날짜를 선택하면 그 날짜 1일치 예약 가능 시간만 계산합니다.
- Supabase에서 전체 예약/원데이/외부 차단 시간을 모두 가져오지 않고 선택한 날짜와 겹치는 데이터만 가져옵니다.
- 자동 조율 슬롯도 선택한 날짜 안에서만 계산합니다.
- 기존 버건디 브랜드 UI, 30분 스마트 슬롯, 자동 조율 슬롯, 외부 예약 차단, 원데이 수업별 신청자 확인 기능은 유지합니다.
