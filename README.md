# 문장학교 예약 앱 - 자동 조율 슬롯 최종 버전

이번 버전에는 30분 단위 스마트 예약 슬롯에 더해, 하루 정규수업 수가 너무 적어질 수 있는 날에는 시스템이 자동으로 10분 단위 조율 슬롯을 추가하는 기능이 포함되어 있습니다.

## 핵심 반영 내용

- 문장학교 버건디 브랜드 UI 유지
- 하단 메뉴 4개 유지: 홈 / 예약내역 / 예약하기 / 프로필
- 7월 1일부터 90분 / 120분 정규수업 규칙 적용
- 정규수업 예약은 기본 30분 단위 유지
- 정규수업 사이에는 30분 휴식 적용
- 하루 마지막 수업은 수업 종료 후 휴식을 강제로 요구하지 않음
- 실제 등록된 원데이 클래스 시간만 정규수업 예약에서 자동 차단
- 관리자 외부 예약 차단 기능 유지
- 90분 수강생 대상 자동 조율 슬롯 추가
  - 일반 30분 슬롯만으로 하루 3명 운영이 어려운 날
  - 기존 수업 후 최소 20분 휴식 확보
  - 원데이 시작 전 최소 10분 준비 시간 확보
  - 하루 최대 1개 추천 시간 자동 표시

## Supabase 안내

이전 `blocked_times` SQL을 이미 실행했다면 새로 실행할 SQL은 없습니다.
처음 적용하는 경우에는 `SUPABASE_MIGRATION.sql`을 Supabase SQL Editor에서 실행해 주세요.
