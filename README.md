# 문장학교 수업 예약 앱 최종 업데이트

이번 버전에는 아래 기능이 포함되어 있습니다.

- 메인/관리자 테스트 안내 문구 삭제
- 관리자 페이지 메뉴 탭 구성
- 예약 가능 시간 삭제 기능
- 원데이 클래스 추가/삭제 기능
- 원데이 클래스 정원 5명 고정
- 원데이 클래스 제목/커리큘럼/일정/비용 표시
- 메인 페이지에 내 수강 기록 확인 메뉴 추가
- 수강생별 정규수업 지난 기록/예약/취소 기록 확인
- 정규수업 80분 안내 + 10분 정리 시간 확보
- 수강권 자동 차감/복구 규칙 유지
- 수업 6시간 전 예약/취소 규칙 유지
