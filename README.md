# 문장학교 예약 시스템

이번 버전에는 수강생 자동 로그인과 원데이 클래스 입금 확인/등록 완료 관리 기능이 포함되어 있습니다.

## 포함 기능
- 정규수업 예약/취소
- 수강 완료 자동 분리
- 원데이 클래스 신청/취소
- 원데이 클래스 신청 후 입금 대기 상태 표시
- 관리자 페이지에서 입금 확인 후 등록 완료 처리
- 수강생 자동 로그인
- 내 수강 기록 확인
- 관리자 페이지 기능 유지

## 업로드 방법
압축을 푼 뒤 바깥 폴더가 아니라 폴더 안의 app, lib, public, package.json 등을 GitHub에 올려 주세요.
