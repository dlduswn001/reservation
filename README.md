# 문장학교 수업 예약 앱

정규수업 예약, 원데이 클래스, 수강권, 과거 수강 기록, 관리자 기능을 포함한 Next.js 예약 앱입니다.

## PWA 설치 기능

이 버전은 휴대폰 홈 화면에 설치할 수 있는 PWA입니다.

- 앱 이름: 문장학교 예약
- 시작 화면: 예약 메인 페이지
- 주소창 없는 독립 실행 화면
- 아이폰 홈 화면 아이콘 지원
- 안드로이드/Chrome 설치 안내 지원
- 인터넷 연결이 끊겼을 때 안내 화면 제공

### 아이폰 설치

Safari에서 사이트를 열고 `공유 → 홈 화면에 추가`를 선택합니다.

### 안드로이드 설치

Chrome에서 사이트를 열고 화면의 `앱 설치하기` 또는 브라우저 메뉴의 `앱 설치`를 선택합니다.

## 배포

GitHub 저장소의 기존 파일 위에 이 폴더 안의 내용물을 업로드합니다. Vercel 배포가 Ready가 된 뒤 HTTPS 도메인에서 설치 기능을 확인합니다.
