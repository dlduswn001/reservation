# 문장학교 예약 시스템 v17

v17은 v15에서 추가한 8월 1일 이후 정규수업 수강권 사용기한 기능을 유지하면서, 관리자 페이지/수강생 페이지 로그인이 막히지 않도록 안정화한 전체 통합본입니다.

## 핵심 반영

- 관리자 페이지 로그인 안정화
- 수강생 로그인 안정화
- Supabase 수강권 사용기한 칼럼이 아직 없어도 기존 로그인과 관리자 홈이 먼저 열리도록 보완
- 2026년 8월 1일 이후 결제/재등록한 4회 수강권에만 사용기한 정책 적용
- 첫 수업일 기준 8주 사용기한 계산
- 1회 최대 2주 연장 관리
- 기존 v14까지의 관리자/원데이/스케줄 기능 유지

## 업로드

압축 해제 후 `app`, `lib`, `public`, `package.json` 등이 보이는 폴더의 전체 내용을 GitHub 저장소 루트에 덮어쓰기 업로드하세요.

## Supabase

수강권 사용기한 기능을 완전히 사용하려면 로그인 정상 확인 후 `SUPABASE_MIGRATION.sql`을 Supabase SQL Editor에서 한 번 실행하세요. v17은 SQL 실행 전에도 기존 로그인과 예약 화면이 먼저 열리도록 만들어져 있습니다.
