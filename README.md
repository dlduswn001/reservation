# 문장학교 예약 앱 - 관리자 원데이 무료 혜택 카운팅 강화

이번 버전은 관리자 페이지의 원데이 신청 목록에서 수강생별 월 1회 무료 혜택 사용 여부와 추가 유료 신청/입금 안내 필요 금액을 더 분명하게 확인할 수 있도록 수정한 버전입니다.

## 포함된 수정

- 월별 원데이 신청 목록에서 무료 혜택 사용 건수 표시
- 월별 원데이 신청 목록에서 추가 유료 신청 건수 표시
- 추가 유료 신청이 있으면 “입금 안내 필요” 문구 표시
- 수강생별 무료 신청 횟수 / 추가 신청 횟수 / 입금 안내 금액 표시
- 개별 신청 카드에도 추가 수강료 입금 안내 필요 문구 표시
- 기존 하단 메뉴형 앱 구조 유지
- 기존 7월 1일 정규수업 시간 정책 유지
- 기존 원데이 월 1회 무료 / 추가 10,000원 자동 계산 유지

## 적용 방법

Supabase에서 새로 실행할 SQL은 없습니다.
GitHub에 전체 파일을 다시 업로드하면 됩니다.
