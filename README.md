# 문장학교 예약 시스템 - 원데이 안내 문구 정리 버전

반영 내용
- 원데이 클래스 카드의 `참가비: 월 1회 무료 / 이후 10,000원` 표시 삭제
- 자세히 보기 하단 신청 완료 안내 문구를 정규수강생에게 더 친절하게 수정
- 신청하기 영역의 비용 안내 문구 수정
- 문장학교 카카오뱅크 계좌 안내 유지
- 기존 기능 유지: 7월 수업시간 정책, 원데이 월 1회 무료/이후 10,000원 자동 계산, 지난 원데이 숨김, 관리자 무료 카운팅, 관리자 달력 정상 취소 숨김

업로드 방법
1. 이 폴더 안으로 들어갑니다.
2. app, lib, public, package.json 등 안의 파일들을 전체 선택합니다.
3. GitHub 저장소에 업로드합니다.
4. Vercel 배포가 Ready가 되면 반영됩니다.

Supabase에서 새로 실행할 SQL은 없습니다.
