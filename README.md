# 문장학교 예약 시스템 전체 통합본 v8

관리자 홈 화면에 들어오자마자 오늘의 수업 일정이 가장 먼저 보이도록 수정한 전체 프로젝트 파일입니다.

## v8 핵심 수정

- 관리자 페이지 홈 최상단에 `오늘의 수업 일정` 영역을 배치했습니다.
- 오늘 진행할 정규수업, 외부 차단/체험수업, 원데이 클래스를 시간순으로 표시합니다.
- 오늘 일정이 없는 경우에는 바로 아래에 `오늘부터 한 달 일정`이 날짜별로 표시됩니다.
- 기존의 `홈` 통계 카드가 먼저 뜨지 않도록 `운영 요약`으로 아래쪽에 배치했습니다.
- 관리자 메뉴는 `홈 / 스케줄 / 수강생 / 원데이 / 설정` 구조를 유지합니다.

## 업로드 주의

GitHub에는 이 폴더 안의 파일들을 프로젝트 루트에 올려야 합니다.
`munjang-full-build` 같은 폴더를 한 겹 더 만든 상태로 올리면 Vercel이 기존 코드를 계속 볼 수 있습니다.
