# 문장학교 수업 예약 앱

정규수업 예약, 원데이 클래스, 수강권, 과거 수강 기록, 관리자 기능을 포함한 Next.js 예약 앱입니다.

## PWA 설치 기능

이 버전은 휴대폰 홈 화면에 설치할 수 있는 PWA입니다.

- 앱 이름: 문장학교 예약
- 시작 화면: 예약 메인 페이지
- 주소창 없는 독립 실행 화면
- 아이폰 홈 화면 아이콘 지원
- 안드로이드/Chrome 설치 안내 지원
- 인터넷 연결이 끊겼을 때 안내 화면 제공

### 아이폰 설치

Safari에서 사이트를 열고 `공유 → 홈 화면에 추가`를 선택합니다.

### 안드로이드 설치

Chrome에서 사이트를 열고 화면의 `앱 설치하기` 또는 브라우저 메뉴의 `앱 설치`를 선택합니다.

## 배포

GitHub 저장소의 기존 파일 위에 이 폴더 안의 내용물을 업로드합니다. Vercel 배포가 Ready가 된 뒤 HTTPS 도메인에서 설치 기능을 확인합니다.

## 2026-06-18 수강 완료 자동 처리 수정

- 정규수업 종료 시간이 지나면 예약 상태를 자동으로 `done`으로 변경합니다.
- 수강생 화면에는 `수강 완료`로 표시되고 취소 버튼이 사라집니다.
- 수업 시작 이후 또는 종료 이후에는 취소 API에서도 취소를 거절합니다.
- 화면을 계속 열어둔 경우에도 30초마다 현재 시간을 확인해 상태와 버튼을 갱신합니다.

## 정규수업 화면 구분
- 예정된 수업과 완료한 수업을 별도 탭으로 표시합니다.
- 수업 종료 시간이 지나면 자동으로 완료한 수업 탭으로 이동합니다.
- 완료한 수업에는 취소 버튼이 표시되지 않습니다.

## 내 수강 기록 화면 정리
- 다가오는 수업은 정규수업과 원데이 클래스를 한 목록으로 표시합니다.
- 다가오는 정규수업은 `예약 완료(booked)` 상태만 표시하며 취소 완료 내역은 숨깁니다.
- 지난 정규수업, 원데이 수업, 관리자 직접 입력 기록은 `수강 기록` 한 목록으로 합칩니다.
- 각 기록의 메모에서 `수강생 직접 예약` 또는 `관리자 직접 등록` 여부를 확인할 수 있습니다.

## 원데이 클래스 신청 취소 기능

- 원데이 클래스 메뉴에서 이름과 핸드폰번호 뒷자리로 신청 내역을 조회할 수 있습니다.
- 수업 시작 6시간 전까지만 신청 취소가 가능합니다.
- 취소된 신청은 정원 계산에서 즉시 제외되어 남은 자리가 복구됩니다.
- 이미 시작했거나 종료된 클래스, 취소 마감 이후의 신청은 취소할 수 없습니다.


## 원데이 클래스 예약 규칙
- 원데이 클래스는 등록된 정규 수강생만 신청할 수 있습니다.
- `정규 수강생입니다` 체크박스는 제거했습니다.
- 모든 원데이 신청은 정규 수강생으로 자동 처리됩니다.
- 신청 취소는 수업 시작 6시간 전까지만 가능합니다.
