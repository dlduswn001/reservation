# 문장학교 예약 앱 - 브랜딩 UI 적용 버전

이번 버전은 기존 예약 기능을 유지하면서 수강생 화면에 문장학교 브랜딩 UI를 적용한 버전입니다.

## 반영 내용

- 따뜻한 베이지/브라운 중심의 문장학교 예약 앱 디자인 적용
- 홈 화면 카드형 UI 정리
- 예약하기 화면을 정규수업/원데이 선택형 허브로 정리
- 프로필 화면을 브랜딩 카드형으로 정리
- 하단 메뉴 4개 유지: 홈 / 예약내역 / 예약하기 / 프로필
- 관리자 메뉴는 수강생 메인에 노출하지 않음
- 기존 정규수업 예약, 원데이 신청, 자동 로그인, 관리자 기능 유지
