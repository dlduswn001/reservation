# 문장학교 예약 시스템 전체 통합본 v7

관리자 홈 화면에 들어오자마자 오늘부터 한 달 동안의 수업 일정을 날짜별로 확인할 수 있도록 수정한 버전입니다.

## v7 반영 내용
- 관리자 페이지 첫 화면에 `오늘의 수업` 영역을 가장 먼저 표시
- 오늘부터 한 달 동안의 일정을 날짜별로 그룹화
- 정규수업 / 외부 차단·체험수업 / 원데이 클래스를 한 화면에서 시간순으로 확인
- 오늘 일정 건수 요약 표시: 오늘 정규수업 / 오늘 외부·체험 / 오늘 원데이
- 일정이 없는 경우 안내 문구 표시
- 기존 관리자 메뉴 구조 유지: 홈 / 스케줄 / 수강생 / 원데이 / 설정
- 기존 기능 유지: 통합 스케줄, 외부 차단 추가·삭제, 정규수업 시간 변경, 원데이 신청자 관리, 한 달 단위 정규수업 예약

## 업로드 방법
압축을 풀고 GitHub 저장소 루트 기준으로 전체 파일을 업로드하세요.
기존 파일과 같은 위치에 덮어쓰기하면 됩니다.

## Supabase SQL
v6에서 이미 SQL을 실행했다면 새로 실행할 SQL은 없습니다.
처음 설치하는 경우에는 아래 SQL 파일을 Supabase SQL Editor에서 실행하세요.

1. `SUPABASE_MIGRATION.sql`
2. `SUPABASE_UNIFIED_SCHEDULE_V2.sql`
3. `SUPABASE_SPEED_INDEXES.sql`
