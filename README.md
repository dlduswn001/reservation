# 문장학교 예약 시스템 전체 통합본 v13

전체 프로젝트 파일입니다. GitHub 저장소 루트에 그대로 덮어쓰기 업로드하면 됩니다.

## v13 핵심 수정

- 관리자 페이지 `원데이` 탭에 생성된 원데이 클래스 삭제 기능을 추가했습니다.
- 삭제한 원데이 클래스는 수강생 원데이 신청 화면과 관리자 원데이 클래스 목록에서 사라집니다.
- 기존 신청자 기록은 삭제하지 않고 보존합니다.
- Supabase에 `oneday_classes.is_deleted` 컬럼을 추가하는 SQL을 포함했습니다.
- 기존 DB에 새 컬럼을 아직 실행하지 않은 상태에서도 삭제 요청은 수강생 화면에서 우선 숨김 처리되도록 fallback을 넣었습니다.

## 기존 반영 유지

- 정규수업 예약 신청: 수업 시작 3시간 전까지 가능
- 정규수업 취소: 수업 시작 3시간 전까지 가능
- 수업 시작 3시간 이내 취소 시 수강권 차감 유지
- 관리자 원데이 클래스 수정 기능
- 관리자 홈 최상단 `오늘의 수업 일정`
- 오늘부터 한 달 일정 일자별 표시
- 관리자 메뉴 `홈 / 스케줄 / 수강생 / 원데이 / 설정`
- 수강권 0회 수강생 관리자 홈 표시

## Supabase SQL

압축 안의 `SUPABASE_MIGRATION.sql`을 Supabase SQL Editor에서 한 번 실행해 주세요.
이미 이전 버전을 실행했어도 다시 실행해도 괜찮게 작성되어 있습니다.
