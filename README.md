# 문장학교 수업 예약 앱

이번 버전에서는 `내 수강 기록` 화면에 원데이 클래스 신청 기록도 함께 표시됩니다.

## 추가된 내용

- 원데이 클래스 신청 내역을 수강생 계정과 연결
- 기존 신청 기록도 이름과 핸드폰번호 뒷자리가 일치하면 자동 연결
- 내 수강 기록에서 원데이 클래스 제목, 일정, 신청 인원, 상태, 적용 비용, 커리큘럼 확인
- 새 원데이 신청 시 일치하는 수강생 계정의 `student_id` 자동 저장

## 적용 순서

1. Supabase SQL Editor에서 `SUPABASE_MIGRATION.sql` 전체 실행
2. GitHub 저장소에 이 폴더 안의 파일과 폴더를 업로드
3. Vercel 최신 배포가 Ready가 될 때까지 대기
4. 메인 페이지의 `내 수강 기록 확인하기`에서 확인
