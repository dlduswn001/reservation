# 문장학교 예약 시스템 전체 통합본 v11

전체 프로젝트 파일입니다. GitHub 저장소 루트에 그대로 덮어쓰기 업로드하면 됩니다.

## v11 핵심 수정

- 관리자 홈에 `수강권 0회` 요약 카드를 추가했습니다.
- 관리자 홈에 `수강권 0회 수강생` 목록을 따로 표시합니다.
- 수강생 관리 탭에도 `수강권 0회 수강생` 목록을 추가했습니다.
- 수강생 목록에서 수강권이 0회인 활성 수강생에게 `수강권 0회` 배지를 표시합니다.
- 수강권을 추가 등록하면 해당 수강생은 0회 목록에서 자동으로 사라집니다.

## 기존 반영 유지

- 관리자 홈 최상단 `오늘의 수업 일정`
- 오늘부터 한 달 일정 일자별 표시
- 관리자 메뉴 `홈 / 스케줄 / 수강생 / 원데이 / 설정`
- 정규수업 예약 신청: 수업 시작 3시간 전까지 가능
- 정규수업 취소: 수업 시작 6시간 전까지 가능, 6시간 이내 취소 시 수강권 차감 유지

## 업로드 주의

압축을 풀었을 때 `app`, `lib`, `public`, `package.json`이 바로 보여야 합니다.
GitHub에는 ZIP 파일 자체가 아니라, 압축을 푼 폴더 안의 전체 파일을 저장소 맨 바깥 루트에 덮어쓰기 업로드해 주세요.
