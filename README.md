# 문장학교 예약 앱 - 원데이 신청자 수업별 확인

관리자 페이지 원데이 탭에서 신청 내역을 전체로 보거나, 원데이 클래스별로 선택해서 해당 수업 신청자만 확인할 수 있게 수정한 버전입니다.

## 반영 내용
- 관리자 페이지 → 원데이 → 신청자 확인 영역에 `수업별 신청자 보기` 선택창 추가
- 전체 원데이 신청 내역 / 특정 원데이 수업 신청자 목록 전환 가능
- 선택한 수업의 총 신청, 활성 신청, 대기, 등록 완료, 취소 건수 표시
- 기존 무료 혜택 카운팅, 추가 유료 신청 카운팅, 입금 확인/등록 완료 기능 유지
- 기존 문장학교 버건디 UI, 스마트 슬롯, 외부 예약 차단, 자동 조율 슬롯 기능 유지
