# 문장학교 예약 시스템 v18

v18은 수강생 정규수업 예약 화면에서 8월 시간표가 보이지 않고 7월 일정만 보이던 문제를 수정한 전체 통합본입니다.

- 월말(25일 이후)에 다음 달 스케줄이 생성되어 있으면 다음 달 일정이 먼저 표시됩니다.
- 다음 달 스케줄이 없으면 기존처럼 이번 달 예약 가능 일정이 표시됩니다.
- 화면에는 한 달 단위 일정만 보여 속도 저하를 줄입니다.
- v17의 로그인 안정화와 8월 1일 이후 수강권 사용기한 정책은 유지합니다.

업로드 방법: ZIP 압축을 풀고 app, lib, public, package.json 등이 보이는 위치의 전체 파일을 GitHub 저장소 루트에 덮어쓰기 업로드하세요.
