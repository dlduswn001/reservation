문장학교 원데이 클래스 가독성 UI 패치

변경 파일은 2개뿐입니다.
1) app/oneday/page.tsx
2) app/globals.css

GitHub 웹에서 안전하게 올리는 방법
1. 저장소의 app/oneday 폴더로 들어갑니다.
2. Add file > Upload files에서 이 패치의 app/oneday/page.tsx 파일만 올립니다.
3. Commit changes를 누릅니다.
4. 저장소의 app 폴더로 들어갑니다.
5. Add file > Upload files에서 이 패치의 app/globals.css 파일만 올립니다.
6. Commit changes를 누릅니다.

Supabase SQL 실행은 필요 없습니다.
