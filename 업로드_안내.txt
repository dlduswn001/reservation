문장학교 예약 시스템 전체 통합본 v9

이번 버전은 관리자 홈 첫 화면이 반드시 [오늘의 수업 일정]으로 시작하도록 정리했습니다.
또한 PWA/브라우저 캐시 때문에 이전 화면이 계속 보이는 문제를 막기 위해 서비스워커 캐시 버전을 v9로 올리고, 이전 캐시를 자동 삭제하도록 수정했습니다.

업로드 방법
1. ZIP 압축을 풉니다.
2. 압축을 풀었을 때 app, lib, public, package.json이 바로 보여야 합니다.
3. GitHub 저장소 루트에 이 내용 전체를 덮어쓰기 업로드합니다.
4. ZIP 파일 자체를 GitHub에 올리면 안 됩니다. 압축을 푼 안쪽 파일/폴더를 올려야 합니다.
5. Vercel 최신 배포가 Ready가 된 뒤 /admin에 접속합니다.
6. 화면에 [오늘의 수업 일정] 문구와 v9 문구가 보이면 성공입니다.

만약 이전 화면이 계속 보이면 브라우저 새로고침을 한 번 더 하거나, Safari/Chrome에서 사이트 데이터 삭제 후 접속해 주세요.
